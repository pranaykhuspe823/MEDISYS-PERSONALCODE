Fingerprint scanner not working? Checklist ▾
  1. Is RD Service installed and running? Check the Windows system tray for the Mantra RD Service icon, or open http://127.0.0.1:11100/rd/info directly in a browser tab — it should return XML, not a connection error.
  2. Is the MFS110 plugged in? Check Windows Device Manager for the device listed under a driver-related category with no warning icon.
  3. Are you on http://localhost, not a remote/LAN address? Fingerprint capture only works when the browser and RD Service are on the same machine.
  4. Still failing with "Failed to fetch" even though step 1 works? Ask whoever manages the MEDISYS server to confirm http://127.0.0.1:11100 is present in the server's Content-Security-Policy connect-src list (server/server.js) — a missing entry there blocks every browser identically, with no visible error beyond this generic message.
  5. RD Service answers but the scanner's light never comes on? A capture request can reach RD Service fine (errCode="700" errInfo="Capture timed out" after 20s) without the light activating if the sensor itself has a driver/USB fault — reseat the USB connection or try a different port.
